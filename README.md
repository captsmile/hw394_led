# LED Matrix Clock — ESP8266

Годинник на LED-матриці MAX7219 (8×32) на базі ESP8266 (ESP-12E). Відображає дату/час та погоду, що чергуються. Налаштовується через веб-портал.

## Функції

- Час та дата з NTP-синхронізацією (раз на годину)
- Поточна погода та прогноз на 12 годин — OpenWeatherMap API
- Чергування екранів: дата/час (10 с) → погода (8 с)
- Веб-портал налаштування у режимі AP
- Зберігання конфігурації в EEPROM

## Схема підключення

| ESP8266 | MAX7219 (FC-16) |
|---|---|
| GPIO2 (D4) | DATA |
| GPIO0 (D3) | CS |
| GPIO4 (D2) | CLK |

Підключіть 8 модулів MAX7219 послідовно (4 — нижня зона, 4 — верхня).

## Перше налаштування

При першому запуску (або якщо конфіг не збережено) пристрій піднімає точку доступу:

- **SSID:** `ClockSetup`
- **Пароль:** `12345678`
- **Адреса:** `192.168.4.1`

Відкрийте `http://192.168.4.1` у браузері та заповніть:

| Поле | Опис |
|---|---|
| WiFi SSID | Ім'я вашої мережі |
| Password | Пароль WiFi |
| Timezone (POSIX) | Наприклад: `EET-2EEST,M3.5.0/3,M10.5.0/4` (Україна) |
| City | Місто для погоди (напр. `Kyiv`) |
| OpenWeatherMap API Key | Безкоштовний ключ з [openweathermap.org](https://openweathermap.org/api) |

Після збереження пристрій перезавантажується і підключається до WiFi.

## Збірка та прошивка

```bash
# Збірка
pio run

# Прошивка
pio run --target upload

# Монітор порту
pio device monitor --baud 9600
```

## Безпека

- WiFi-пароль та API-ключ зберігаються в EEPROM пристрою, не в коді.
- Пароль AP `12345678` — публічний дефолт для першого налаштування; змінити його можна у `web_portal.cpp:34`.
- Запити до OpenWeatherMap йдуть через HTTP (не HTTPS) — обмеження ESP8266 без TLS.
